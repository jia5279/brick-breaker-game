# Brick Breaker Game

A browser-based brick breaker game with smooth keyboard controls, light/dark themes, and a local top-10 ranking board.

## Play

Open `outputs/brick-breaker.html` in a modern web browser.

- Move with the mouse, touch, or the arrow keys / A and D.
- Use the theme button in the upper-right corner to switch between light and dark modes.
- Scores are saved in the current browser using local storage.
